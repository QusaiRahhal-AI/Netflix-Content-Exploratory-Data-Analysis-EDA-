# Netflix Content Exploratory Data Analysis (EDA)

## Project Overview
An exploratory data analysis project examining Netflix's content catalog to uncover trends in content distribution, release years, country of origin, and the balance between movies and TV shows.

## Dataset
- **Source:** Kaggle - Netflix Movies and TV Shows
- **Dataset Link:** [https://www.kaggle.com/datasets/ariyoomotade/netflix-data-cleaning-analysis-and-visualization]

## Analysis & Methodology
1. **Data Cleaning & Manipulation:**
   - Handled missing values in metadata such as director, cast, and country fields.
   - Converted date formats to extract temporal trends and publishing patterns over the years.
2. **Exploratory Data Analysis (EDA):**
   - Analyzed the growth rate of movie additions versus television shows over time.
   - Examined top producing countries and categorized content distribution across genres.
3. **Data Visualization:**
   - Utilized statistical plotting libraries to map distributions, correlation structures, and catalog growth timelines.
